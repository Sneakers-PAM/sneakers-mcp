# sneakers-mcp 🐹

> 🧭 Sneakers MCP server for AI agents, plus the sneakers-run and sneakers-put CLIs

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-mcp
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
